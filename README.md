
🏥 Healthcare Insurance Cost Analysis Dashboard

An interactive Tableau dashboard analyzing health, lifestyle, and demographic factors that relate to insurance pricing across 25,000 applicants.

📊 Project Overview

Insurance companies price policies based on a mix of health indicators and lifestyle habits — but which factors actually move the needle? This project explores that question using a real-world-style dataset of insurance applicants, visualized in Tableau.



🎯 Objective

To identify which demographic and lifestyle factors — occupation, location, cholesterol level, and alcohol consumption — correlate most strongly with insurance cost, and present the findings in an easy-to-explore visual format.

🗂️ Dataset
📄 25,000 applicant records
🧬 24 fields covering health metrics (BMI, glucose level, cholesterol, heart disease history), lifestyle habits (smoking, alcohol, exercise), and demographics (age, gender, occupation, location)
🎯 Target variable: insurance_cost


🛠️ Tools Used
📈 Tableau Public — dashboard design & visualization
🧮 Excel — source data


📌 Visualizations Included
🗺️ Geographic map — average insurance cost by city
📉 Distribution histogram — spread of insurance cost across all applicants
💼 Insurance cost by occupation
🩸 Insurance cost by cholesterol level
🍷 Insurance cost by alcohol frequency
🔢 KPI summary — key metrics at a glance
